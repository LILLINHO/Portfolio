Meus Projetos

Projeto Cafeteria

Este projeto consiste em uma página web responsiva para uma cafeteria fictícia, desenvolvida utilizando HTML5 e CSS3. O design apresenta um layout moderno e acolhedor, adequado para um estabelecimento de café, com ênfase na experiência do usuário e na apresentação visual dos produtos.

TODO List

Este projeto é uma aplicação web interativa de lista de tarefas (To-Do List), desenvolvida com HTML, CSS e JavaScript. Ele permite que os usuários adicionem, marquem como concluídas, editem e excluam tarefas, proporcionando uma maneira simples e eficiente de organizar suas atividades diárias.

Cardapio

Este projeto é um cardápio digital interativo para bares, cafés ou restaurantes, desenvolvido com HTML, CSS e JavaScript. Ele permite exibir bebidas de forma organizada, com filtros por categorias, busca por nome e detalhes de cada item, proporcionando uma experiência intuitiva para clientes e facilitando a navegação no menu.
